## [Unreleased]

### Added
- Initial release
- Media player integration for Yamaha Legacy Receiver
- Power control (on/off)
- Volume control (set, up, down)

- Input source selection
- Sound mode (surround) selection
- Multi-zone support (Main, Zone 2, 3, 4)
- UI-based configuration flow
- German and English translations

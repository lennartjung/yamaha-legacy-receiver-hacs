# Repository auf Public setzen

## Warum Public?

HACS (Home Assistant Community Store) kann nur auf **öffentliche** GitHub Repositories zugreifen. Private Repositories funktionieren nicht.

## Schritt-für-Schritt Anleitung

### 1. Gehe zu deinem Repository auf GitHub:
https://github.com/lennartjung/yamaha-legacy-receiver-hacs

### 2. Click auf **Settings** (oben rechts)

### 3. Scrolle ganz nach unten zu **Danger Zone**

### 4. Click auf **Change visibility**

### 5. Wähle **Make public**

### 6. Bestätige mit dem Repository-Namen: `lennartjung/yamaha-legacy-receiver-hacs`

### 7. Click **I understand, change repository visibility**

## ✅ Fertig!

Das Repository ist jetzt öffentlich und HACS kann darauf zugreifen.

## Sicherheit

**Keine Sorge:** In diesem Repository sind keine privaten Daten:
- ❌ Keine Passwörter
- ❌ Keine API-Keys
- ❌ Keine IP-Adressen (außer Beispielen)
- ❌ Keine persönlichen Daten

Es ist Standard-Practice, Open-Source Integrationen öffentlich zu teilen!

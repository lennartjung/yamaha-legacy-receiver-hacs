# Brand Assets

This directory contains the branding assets for the Yamaha Legacy Receiver integration.

## Current Icon

A placeholder SVG icon is provided (`logo.svg`). 

## Replace with Proper Icon

To add a proper Yamaha logo:

1. Create or download a Yamaha AV Receiver icon (256x256px, PNG format)
2. Save it as `icon.png` in this directory
3. Commit and push the changes

## Requirements

- **Format:** PNG
- **Size:** 256x256 pixels (minimum), recommended 512x512
- **Background:** Transparent preferred
- **Content:** Should represent Yamaha or AV Receiver

The current placeholder satisfies HACS validation but should be replaced with a proper icon for better user experience.

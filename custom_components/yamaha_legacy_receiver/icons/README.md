# Icons for Yamaha Legacy Receiver

This directory will contain the integration icons.

For now, Home Assistant will use the default media player icon.

## Optional: Add Custom Icon

To add a custom icon:
1. Create `icon.png` (256x256px)
2. Create `icon@2x.png` (512x512px) 
3. Commit and push

Icon should be:
- Square format (1:1 ratio)
- PNG format
- Transparent background preferred
- Represents Yamaha or AV Receiver
